# depgraph

Инструмент визуализации графа зависимостей пакетов Alpine Linux (apk).
Практическая работа «Конфигурационное управление», вариант 27.

## 1. Общее описание

Консольное приложение на Python (только стандартная библиотека). Строит
граф зависимостей пакета с учётом транзитивности, максимальной глубины и
фильтра по имени. Менеджеры пакетов и сторонние библиотеки для получения
зависимостей не используются.

Состояние проекта: **этап 4** — дополнительные операции. Граф строится
обходом в ширину (BFS) без рекурсии, циклы обрабатываются, есть тестовый
режим с файлом-описанием репозитория и режим обратных зависимостей.

## 2. Описание функций и настроек

| Параметр | Описание |
|---|---|
| `-p`, `--package NAME` | имя анализируемого пакета (обязательный) |
| `-r`, `--repo URL\|FILE` | URL репозитория или путь к файлу тестового репозитория (обязательный) |
| `-t`, `--test-mode` | считать `--repo` путём к файлу тестового репозитория |
| `-V`, `--pkg-version VERSION` | версия пакета (обязательна для реального репозитория, в тестовом режиме не используется) |
| `-o`, `--output FILE.png` | имя файла с изображением графа (по умолчанию `graph.png`) |
| `-a`, `--ascii-tree` | вывести зависимости в виде ASCII-дерева |
| `-d`, `--max-depth N` | максимальная глубина анализа, целое от 1 (по умолчанию 3) |
| `-f`, `--filter TEXT` | не учитывать пакеты, в имени которых есть подстрока |
| `--reverse` | вывести обратные зависимости: пакеты, которые зависят от заданного |
| `--show-params` | напечатать все параметры в формате `ключ=значение` |

Коды завершения: 0 — успех, 1 — ошибка данных или сети, 2 — ошибка
параметров.

**Реальный репозиторий.** По `--repo` формируется адрес
`<repo>/APKINDEX.tar.gz`, архив скачивается через `urllib` и читается через
`tarfile`. Используются поля записи `P` (имя), `V` (версия), `D`
(зависимости), `p` (что предоставляет пакет). Зависимости вида
`so:libc.musl-x86_64.so.1` и `cmd:sh` заменяются пакетом-поставщиком,
версионные ограничения (`>=1.2`) отбрасываются, конфликты (`!name`)
пропускаются, зависимость пакета от собственного `so:` не считается.
Зависимость, которой нет в индексе, остаётся листом под своим именем.
Если версия не найдена, программа покажет доступные.

**Тестовый репозиторий.** Текстовый файл, по строке на пакет:
`A: B C` (после двоеточия список зависимостей, возможно пустой). Имена —
из больших латинских букв; `#` начинает строку-комментарий. Примеры лежат
в папке `examples/`.

**Алгоритм.** Обход в ширину с очередью (`collections.deque`) и множеством
посещённых узлов. Корень имеет глубину 0, узлы на глубине `--max-depth`
включаются в граф, но не раскрываются. Пакеты, в имени которых есть
подстрока `--filter`, пропускаются вместе с рёбрами к ним (если исключён
корень — ошибка). Узел обрабатывается один раз, поэтому циклы не
зацикливают обход; ребро, замыкающее цикл, остаётся в графе, а циклы
перечисляются в отчёте (итеративный поиск в глубину).

**Обратные зависимости.** С параметром `--reverse` используется тот же
обход в ширину (`build_graph`), но соседями узла служат не его
зависимости, а пакеты, которые напрямую от него зависят (`dependents`).
Для реального репозитория карта «пакет -> зависящие от него» строится по
всему индексу с теми же правилами разбора `D` и `p`. Глубина и фильтр
действуют так же. Цикл в отчёте печатается в направлении зависимостей.

Модули: `config.py` (параметры и проверка), `fetch.py` (загрузка по URL),
`apk.py` (разбор индекса Alpine), `filerepo.py` (тестовый репозиторий),
`graph.py` (BFS и поиск циклов), `report.py` (текстовый отчёт),
`cli.py` (запуск), `main.py` (точка входа).

## 3. Сборка и запуск тестов

Сборка не нужна. Требуется Python 3.8 или новее.

```
run.bat test          # Windows
./run.sh test         # Linux и macOS
python -m unittest discover -s tests -t .
```

## 4. Примеры использования

Тестовый режим на файлах из `examples/`.

Дерево без повторов:

```
run.bat -p A -r examples/tree.txt -t
Граф зависимостей пакета A (обход в ширину, глубина не более 3)
Узлов: 6, рёбер: 5
  A (глубина 0) -> B, C
  B (глубина 1) -> D, E
  C (глубина 1) -> F
  D (глубина 2) -> (нет)
  E (глубина 2) -> (нет)
  F (глубина 2) -> (нет)
Циклических зависимостей нет
```

Циклическая зависимость (граф конечен, цикл найден):

```
run.bat -p A -r examples/cycle.txt -t
Граф зависимостей пакета A (обход в ширину, глубина не более 3)
Узлов: 4, рёбер: 4
  A (глубина 0) -> B
  B (глубина 1) -> C
  C (глубина 2) -> A, D
  D (глубина 3) -> (нет)
Циклические зависимости (1):
  A -> B -> C -> A
```

Ограничение глубины:

```
run.bat -p A -r examples/chain.txt -t -d 2
Граф зависимостей пакета A (обход в ширину, глубина не более 2)
Узлов: 3, рёбер: 2
  A (глубина 0) -> B
  B (глубина 1) -> C
  C (глубина 2) -> (нет)
Циклических зависимостей нет
```

Фильтр по подстроке (LIBA и LIBB исключены):

```
run.bat -p APP -r examples/filter.txt -t -f LIB
Граф зависимостей пакета APP (обход в ширину, глубина не более 3)
Узлов: 2, рёбер: 1
  APP (глубина 0) -> CORE
  CORE (глубина 1) -> (нет)
Циклических зависимостей нет
```

Обратные зависимости (`--reverse`): кто зависит от пакета.

```
run.bat -p D -r examples/diamond.txt -t --reverse
Обратные зависимости пакета D (пакеты, которые от него зависят), глубина не более 3:
  B (глубина 1) -> зависит от: D
  C (глубина 1) -> зависит от: D
  A (глубина 2) -> зависит от: B, C
Всего: 3
Циклических зависимостей нет
```

```
run.bat -p A -r examples/cycle.txt -t --reverse
Обратные зависимости пакета A (пакеты, которые от него зависят), глубина не более 3:
  C (глубина 1) -> зависит от: A
  B (глубина 2) -> зависит от: C
Всего: 2
Циклические зависимости (1):
  A -> B -> C -> A
```

```
run.bat -p E -r examples/chain.txt -t --reverse -d 2
Обратные зависимости пакета E (пакеты, которые от него зависят), глубина не более 2:
  D (глубина 1) -> зависит от: E
  C (глубина 2) -> зависит от: D
Всего: 2
Циклических зависимостей нет
```

```
run.bat -p CORE -r examples/filter.txt -t --reverse -f LIB
Обратные зависимости пакета CORE (пакеты, которые от него зависят), глубина не более 3:
  APP (глубина 1) -> зависит от: CORE
  UTIL (глубина 1) -> зависит от: CORE
Всего: 2
Циклических зависимостей нет
```

Ошибки:

```
run.bat -p Z -r examples/tree.txt -t
Ошибка: пакет Z не найден в тестовом репозитории; есть пакеты: A, B, C, D, E, F
```

```
run.bat -p A -r README.md -t
Ошибка: строка 3: ожидается вид «A: B C» (имена из больших латинских букв)
```

```
run.bat -p A -r examples/tree.txt -t -d 0
usage: depgraph [-h] -p NAME -r URL|FILE [-t] [-V VERSION] [-d N] [--reverse]
                [-f TEXT] [-o FILE.png] [-a] [--show-params]
depgraph: error: argument -d/--max-depth: глубина должна быть не меньше 1, получено 0
```

Реальный репозиторий. Если версия неизвестна, укажите любую: программа
сообщит доступные.

```
run.bat -p busybox -r https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64 -V 0
run.bat -p busybox -r https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64 -V <версия> -d 2
```
